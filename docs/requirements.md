# 요구사항 정의서

버전 v0.1 · 2026-11-25 · 구현 전 제안

## 목표와 범위

사용자가 제도 이름이나 자격 기준을 몰라도 자신의 상황을 말하면 관련 지원을 탐색하고 신청 준비를 진행할 수 있게 한다. 첫 대상은 개인이며 중앙정부·경기도·안산시의 확보 가능한 공식 공고로 시작한다. 실제 수집 범위를 화면에 공개한다. 대화에 등장한 이름·나이·지역은 예시이며 기본 프로필이나 실사용자 테스트 데이터로 저장하지 않는다.

| MVP 포함 | 후속 검토 |
|---|---|
| 익명 상담, 자연어 입력, 사실 확인·수정 | 회원가입, 소셜 로그인, 장기 프로필 |
| 추가 질문·건너뛰기·현재 정보로 결과 보기 | 알림, 가족별 프로필, 다국어 |
| 근거 기반 추천·검색·상세 | 전국 기관 확대, 의미 검색 |
| 신청 준비 목록·체크리스트·사용자 상태 기록 | 서류 업로드, 기관 API 연동 |
| 상담 삭제·만료 | 자동 신청·대리 제출, 심사 결과 자동 조회 |

## 기능 요구사항

| ID | 요구사항 | 인수 기준 |
|---|---|---|
| F01 | 동의 후 익명 상담 시작 | 동의 버전·시각 기록, 토큰 없이는 상담 접근 불가 |
| F02 | 자기소개 분석 | “25살, 안산 거주”를 제안하고 만 나이·주민등록지 여부를 추측하지 않음 |
| F03 | 정보 확인·수정 | 확인된 필드만 판단에 사용, 수정 시 프로필 버전 증가 |
| F04 | 관련 추가 질문 | 후보 조건에 근거해 월세·취업·가구 등 질문 이유 표시 |
| F05 | 응답 생략 | 모름·건너뛰기를 false/0으로 저장하지 않음, 현재 정보로 추천 가능 |
| F06 | 조건별 추천 | 충족 가능·추가 확인·불일치와 조건별 근거 표시 |
| F07 | 접수 상태 | 접수 전·접수 중·마감·확인 필요를 자격과 별도 표시 |
| F08 | 검색·상세 | 분야·지역·접수 필터, 공고 원문·출처·확인 시각 제공 |
| F09 | 신청 준비 | 근거로 단계·서류 생성, 미확인 내용 명시 |
| F10 | 준비 상태 기록 | 준비 중·사용자 제출 기록·취소 및 체크 여부 저장 |
| F11 | 재평가 | 정보나 공고 변경 시 과거 결과 변경 안내 |
| F12 | 삭제·만료 | 토큰 무효화, 관련 개인정보 삭제 |
| F13 | 수집 운영 | 중복 방지, 새 버전 저장, 실패 시 기존 데이터 유지 |

## 비기능 요구사항

| ID | 요구사항 | 검증 기준 또는 목표 |
|---|---|---|
| N01 | 최소 수집 | 이름·주민번호·계좌·서류 원본은 필수 입력 및 AI 전송 대상에서 제외 |
| N02 | 접근 통제 | 객체별 세션 소유권 검사, 토큰 원문 DB·로그 저장 금지 |
| N03 | 근거 추적 | 추천마다 공고 버전·문단 또는 조건 근거 추적 |
| N04 | 정확성 | 미확인 조건을 충족으로 단정하는 평가 테스트 실패 0건 |
| N05 | 성능 | 목표: 조회 p95 1초, AI 요청 p95 15초, 30초 상한; 부하 조건은 구현 시 확정 |
| N06 | 복원력 | AI·수집 장애 구분, 재시도로 중복 데이터가 생기지 않음 |
| N07 | 접근성 | 키보드 조작, 입력 레이블, 색상 외 텍스트 상태 표시 |

성능 수치는 측정 결과가 아닌 설계 목표다. 완료 시 동의 → 자기소개 → 사실 확인 → 월세 여부 질문 → 추천 → 근거 확인 → 신청 준비 → 삭제 흐름을 시연한다. 정보 부족·소득 기준 불일치·마감·AI 장애·타 세션 접근·공고 변경도 검증한다.
