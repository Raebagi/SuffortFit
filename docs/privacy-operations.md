# 개인정보·운영 정책 초안

2026-11-25 · 제품·개발 정책 제안이며 법적 적합성 검토나 확정된 이용약관이 아니다.

## 수집과 동의

상담 시작 전에 처리 목적, 항목, 보존 기간, 외부 AI 처리 여부, 삭제 방법을 안내하고 안내 버전·동의 시각을 기록한다. 외부 AI 제공자·처리 지역·보존 조건은 선정 후 실제 서비스 안내에 반영한다. 선정 전에는 실사용자 개인정보를 외부 모델로 전송하지 않고 합성 데이터로 개발한다.

이름은 추천에 불필요하므로 별도 필드로 수집하지 않는다. 상세 주소 대신 지역 코드, 원본 서류 대신 준비 여부를 사용한다. 주민번호·계좌번호·인증 정보·신분증을 요구하지 않는다. 민감한 추가 조건은 MVP에서 무리하게 수집하지 않고 공식 공고 확인 필요로 남길 수 있다.

자유 입력에는 개인정보가 포함될 수 있다. 사용자 메시지를 외부 모델에 보내기 전 이름·연락처 등 불필요한 식별자를 제거하는 처리를 둔다. 모델 제공자의 저장·학습 설정을 확인하고 원문 전송 범위를 최소화한다. 마스킹만으로 모든 개인정보가 제거됐다고 가정하지 않는다.

## 보존·삭제 제안

| 데이터 | 보존 | 삭제 방식 |
|---|---|---|
| 상담·메시지·프로필·추천·신청 준비·멱등 응답 | 생성부터 24시간, 사용자 요청 시 즉시 | DB 트랜잭션으로 삭제, 토큰 즉시 무효화 |
| 만료된 상담 | 만료 순간 접근 차단 | 만료 삭제 작업을 1시간마다 실행 |
| 공개 공고·버전·근거 | 과거 추천 설명을 위해 유지 | 개인정보와 분리, 출처 정책 변경 시 재검토 |
| 운영 로그 | 30일 제안 | 순환 삭제, 원문·토큰·소득·사용자 식별 정보 기록 금지 |
| 백업 | MVP 상담 테이블은 지속 백업 제외 | 운영 전 복구 범위 확인; 공고만 백업 가능 |

보존값은 서비스 출시 전 확정한다. 지속 백업에 상담 데이터를 포함하도록 변경할 경우 보존 기한, 삭제 재적용, 복구 후 만료 처리부터 설계한다. 익명 상담은 탭 종료 후 복구하지 못할 수 있으며 시작 화면에 알린다.

## 보안·운영

- TLS, 허용 Origin 기반 CORS, 세션별 객체 권한 검사를 적용한다.
- 비밀키는 환경 설정/비밀 관리 도구에 보관하고 클라이언트 번들·DB 공고·로그에 넣지 않는다.
- 공개 검색과 상담별 AI 호출에 속도 제한을 적용한다.
- 공식 URL은 수집 어댑터의 허용 호스트와 스킴으로 검증한다. AI가 만든 신청 URL을 사용하지 않는다.
- 추천 근거 ID가 실제 검색된 버전에 존재하는지 검사한다. 실패하면 생성 설명을 버리고 구조화된 사실만 반환한다.
- AI 오류율, 응답 시간, 수집 성공 시각, 미확인 조건 비율, 만료 삭제 지연을 관측한다.
- 수집 장애에서는 기존 데이터와 신선도 경고를 제공하고, 기관의 접수 여부를 대신 확정하지 않는다.

## 출시 전 결정

외부 AI 처리 조건, 실제 개인정보 안내문·동의 항목, 데이터 제공처 이용 조건, 보존값, 서비스 운영 주체·문의 창구를 확정한다. 해당 정책의 법률 검토는 별도이며 이 문서에서 법적 의무를 단정하지 않는다.
