# SupportFit (지원핏)

**내 상황을 설명하면, 필요한 정보를 추가로 확인하고 정부·지자체 지원제도 탐색부터 신청 준비까지 돕는 AI 웹 서비스.**

> “경기도 안산시에 사는 25살 남자예요. 받을 수 있는 지원이 있을까요?”
>
> “말씀하신 나이는 만 나이인가요?”, “현재 자취하면서 월세를 내고 있나요?”

사용자가 확인한 정보를 공식 공고의 조건과 비교해 지원제도, 추천 이유, 추가 확인 사항, 신청 기한과 준비 서류를 보여준다. 지원 대상 확정과 실제 접수 결과는 담당 기관에서 결정한다.

## 주요 기능 계획

- 자연어 자기소개에서 지역·연령·주거·취업 정보를 추출하고 사용자에게 확인받기
- 후보 제도의 자격 판단에 필요한 정보만 순서대로 추가 질문하기
- 공식 공고를 검색하고 조건 충족 가능·추가 확인 필요·조건 불일치를 구분하기
- 추천 근거, 원문 링크, 접수 상태, 마지막 확인 시각 제공하기
- 제도별 준비 서류와 신청 단계 체크리스트, 공식 신청 링크 제공하기
- 상담 정보 수정·삭제와 추천 재평가 지원하기

## 현재 상태

기획·설계 단계다. Java 17, Spring Boot 4.1.2, Gradle 기본 프로젝트가 있으며 웹 API·DB·AI·공고 연동은 아직 구현되지 않았다. 문서는 구현할 목표 계약 v0.1이다.

| 구분 | 구성 |
|---|---|
| 현재 | Java 17, Spring Boot 4.1.2, Gradle Wrapper |
| 설계 제안 | Spring MVC, Bean Validation, Spring Data JPA, PostgreSQL, Flyway |
| 미정 | 프런트엔드 기술, AI 제공자·모델, 배포 환경, 첫 공식 데이터 제공처 |

## 로컬 실행

JDK 17을 설치하고 JAVA_HOME을 설정한다. 최초 실행에는 Gradle과 의존성 다운로드가 필요하다.

```powershell
# Windows PowerShell
.\gradlew.bat test
.\gradlew.bat bootRun
```

```bash
# macOS / Linux
./gradlew test
./gradlew bootRun
```

현재는 기본 애플리케이션만 실행된다. 웹 의존성과 컨트롤러가 없어 브라우저 화면이나 API 응답은 제공하지 않는다. DB 및 API 키 환경변수는 연동 구현 단계에서 확정하며 비밀값은 저장소에 커밋하지 않는다.

## MVP 범위

중앙정부·경기도·안산시의 개인 대상 지원을 우선 탐색 범위로 삼되, 실제 제공 범위는 확보한 데이터 출처에 한정한다. 처음부터 전국 모든 제도를 빠짐없이 찾는다고 표시하지 않는다. 로그인, 서류 원본 업로드, 자동 신청·대리 제출, 기관의 심사 결과 자동 조회는 후속 범위다.
