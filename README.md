# SupportFit (지원핏)

사용자의 상황을 이해하고 정부·지자체 지원사업 공고를 바탕으로 맞춤형 사업을 추천하며, 신청 자격과 준비 절차를 안내하는 AI 웹 서비스.

사용자가 “야간대에 다니면서 아르바이트를 하고 있는데 취업 준비 비용과 월세가 부담돼”라고 말하면, 취업 준비와 주거비에 관련된 공고를 함께 찾아 추천 이유, 확인할 자격, 신청 기한, 필요 서류, 공식 링크를 보여준다.

- [프로젝트 설계서](docs/design.md)
- [구현 계획](docs/implementation-plan.md)

현재 Java 17·Spring Boot·Gradle 기본 프로젝트에 설계를 추가한 상태다.
